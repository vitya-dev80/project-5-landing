# 🚀 Portfolio & Digital Agency Landing Page

Сучасний, адаптивний Landing Page для IT-агентства з інтерактивними слайдерами, анімаціями при скролі та інтегрованою формою збору лідів через **Telegram Bot API** та **Web3Forms API**.

## 🛠 Технологічний стек
- **Front-End:** HTML5, CSS3 (Flexbox/Grid, Responsive Design), JavaScript (ES6+), Vite.
- **Бібліотеки та інтерактив:** 
  - [Swiper.js](https://swiperjs.com/) — адаптивний тач-слайдер для портфоліо.
  - [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/) — плавні анімації появи елементів при скролі.
- **Бекенд-інтеграції & API:**
  - **Telegram Bot API** — миттєва відправка сповіщень про нові заявки з сайту в приватний Telegram-чат.
  - **Web3Forms API** — асинхронне дублювання заявок на Email.

---

## ⚡ Ключовий функціонал
1. **100% Адаптивність:** Ідеальне відображення на мобільних пристроях, планшетах та десктопах.
2. **Паралельна (двойна) обробка форми:** При заповненні форми заявка одночасно відправляється і в Telegram, і на пошту без перезавантаження сторінки (AJAX / Fetch API).
3. **Оптимізована продуктивність:** Висока швидкість завантаження завдяки бандлеру Vite та чистому коду.
